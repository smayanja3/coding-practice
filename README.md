# Coding Practice

My daily problem-solving practice, organized by platform. I use this repo to build my skills in JavaScript, data structures, and algorithms.

## Structure

```
coding-practice/
├── CODEWARS/    Kata solutions, organized by kyu rank
├── LEETCODE/    Solutions organized by difficulty
└── NEETCODE/    NeetCode roadmap problems
```

## Platforms

### [Codewars](./CODEWARS)
Kata solutions sorted by rank, from 8 kyu (easiest) to 1 kyu (hardest).
- [8 kyu](./CODEWARS/8-kyu)
- [7 kyu](./CODEWARS/7-kyu)
- [6 kyu](./CODEWARS/6-kyu)

### [LeetCode](./LEETCODE)
Interview-style problems sorted by difficulty.
- [Easy](./LEETCODE/easy)
- [Medium](./LEETCODE/medium)
- [Hard](./LEETCODE/hard)

### [NeetCode](./NEETCODE)
Problems from the NeetCode roadmap, grouped by topic.

## Goals

- Practice a little every day
- Get comfortable with arrays, strings, hash maps, and two pointers
- Work up through the ranks on each platform
